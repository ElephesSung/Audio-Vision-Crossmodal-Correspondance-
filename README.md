## G-MNL 里“必要/建议”的变量放法

### 1) 必备：识别与基线
- **个体ID（panel id）**：每个被试多次选择 → 必须。
- **备选项常数（ASC）**：9 个选项的基线偏好（需**基准化**：选一个作基准或用和为零对比）。
- **试次/刺激属性**：这里最关键的是“**是否匹配**”——即 trial 的动物与视觉选项是否同类（Fish↔Fish 等）。做成指示变量（match=1/0）。
- **呈现顺序/区块（可选但强烈建议）**：控制疲劳/学习（如前半 vs 后半、trial 序号）。

### 2) 个体层协变量（放在哪里）
- **均值效应（“口味”/平均偏好）**：进入效用的系统部分，通常**与备选属性或 ASC 交互**  
  - 视觉意象生动性（VVIQ 等）  
  - 音乐能力（四维）/音乐训练水平  
  - 年龄/性别等
  - **最有信息的交互**：这些分数 × “匹配(match)”（检验“想象力/能力高的人更偏向匹配”）
- **尺度异质性（决策噪声/确定性）**：进入 **scale（误差方差）方程**，解释“有人更‘坚定’、有人更‘随意’”  
  - 建议尝试放：音乐训练、总体能力、注意力指标（如反应时稳定性、漏答率）等  
  - 这些不一定影响“喜欢谁”，但会影响“选择有多确定”。

> 实务建议：**同一协变量不要同时重度放在“均值”和“尺度”里**，先各跑一个版本比较，避免可识别性变差。

### 3) 变量取舍（你给的那几类）
- **视觉意象生动性**：优先放到**均值×匹配**（想象力越强，越偏好“声画一致”？）+ 备选：放到**尺度**（越稳定/越想象力强，决策更确定？）
- **音乐能力四维**：先做**相关性检查/主成分**（高度相关时用 1–2 个因子或总分），再放到**均值×匹配**；有理论时再挑一两维放入**尺度**。
- **音乐训练水平**：常见地更影响**尺度**（训练者更“稳”），也可以与**均值×匹配**交互检验“训练是否更重视一致性”。

## 多层/层级在 G-MNL 中是怎么“识别和计算”的？

把 G-MNL 拆成三层来理解（不写复杂公式，讲可操作的识别点）：

1) **均值层（系统效用）**  
   - 有 **ASC**（每个选项的基线）与**刺激属性**（这里的“匹配”）  
   - **个体变量进来**的两种典型方式：  
     a) **与 ASC/属性交互**：例如（VVIQ × match），让不同人群对“匹配”的权重不同；  
     b) **类成员概率/分段**（若做潜类模型）：这里先不展开。
   - **识别要点**：需要选一个 ASC 作为基准或采用和为零对比；协变量宜**中心化**，避免与 ASC 及随机项共线。

2) **口味异质性层（随机参数）**  
   - 让“对匹配的权重”等在被试间**随机分布**（正态/对数正态等）。  
   - **识别**依赖：同一被试有多次选择（panel），并且属性在不同选择中**有变化**（这里每个 trial 的匹配与否会变化），随机参数才能被分离出来。  
   - **估计**通常用模拟极大似然或贝叶斯（HB）。

3) **尺度异质性层（G-MNL 的关键）**  
   - 允许每个被试有不同的“决策确定性”（误差尺度），并且尺度本身可由个体变量解释（例如 训练、能力）。  
   - **识别**：尺度和效用系数有“同尺度不变性”冲突，所以需**把平均尺度归一（如均值=1）**，并给一个基准（常见做法：固定尺度截距或对某一组的尺度锚定）。  
   - 经验上：**不要同时让太多协变量进入尺度**，否则尺度与均值/随机口味容易缠绕 → 用信息准则/预测检验来选择。

## 变量进入位置的“实操决策树”

1) 你是否对“谁更偏好**声画匹配**”有明确假设？  
   → 有：把该个体变量 × match 放进**均值**。  
2) 你是否认为某变量改变“**选择的确定性**”，但不改变“偏好方向”？  
   → 有：把该变量放进**尺度**。  
3) 多个子维度高度相关？  
   → 先**合成一个总分/因子**（或选择 1–2 个信息量大的），避免多重共线 + 过拟合。  
4) 担心过拟合？  
   → 采用逐步比较：  
   - M0：仅 ASC + match  
   - M1：M0 +（VVIQ × match）  
   - M2：M1 +（训练 放尺度）  
   - M3：M2 +（音乐能力因子 × match）  
   用 **预测表现（LOO/CV）** 和**参数稳定性**决定保留。

## 数据与编码要点（很重要）

- **面板结构**：数据是长表，一行一个“被试×trial×选项”，有 `choice=1/0`，并标好 `id`、`trial`、`alt`。  
- **ASC 编码**：9 个选项用 **和为零对比**（sum-to-zero）或固定一个为基准，避免与截距完全共线。  
- **匹配(match)**：根据 trial 的动物和 alt 是否一致生成二元变量；这是最关键的“属性”。  
- **协变量**：统一 **中心化/标准化**（z-score），方便收敛与解释。  
- **多重选择的情况**：如果保留多选，就不要用 G-MNL，换用 **MDCEV** 或前面给你的**分层 0/1 逻辑**（那一套对多选天生友好）。

## 估计与模型比较（工具与流程）

- **R 工具**：  
  - 如果坚持 G-MNL：推荐 **`gmnl`**（Generalized Mixed Logit）或 **Apollo**（功能更全，支持 G-MNL、潜类、MDCEV）。  
  - 多选：用 **Apollo 的 MDCEV**，或留在我们之前给你的**分层逻辑**（`brms`/`glmmTMB`）。
- **流程**：  
  1) 先跑一个**MNL 基线**（ASC + match），确认方向；  
  2) 加**随机参数**（对 match 的系数设为随机）；  
  3) 再加**尺度异质性**（把训练/VVIQ 放进尺度），逐步比较；  
  4) 用 **LOO/预测率/Top-1 准确率** 比较，并做 **后验预测检验**（或仿真检验）看看能否复现实验里“匹配选项显著更常被选”的现象。

## 最小可落地的变量选择（给你一版“够用不复杂”的首发模型）

- **均值（系统效用）**：  
  - ASC（9 选项，和为零）  
  - `match`  
  - `VVIQ_z × match`  
  - `MusicTraining_z × match`
- **随机口味**：  
  - `match` 的系数设为**随机正态**（个体口味差异）  
- **尺度**：  
  - 尺度 = exp( ω0 + ω1·Training_z )  （先只放训练一个，稳些）

> 这版就能检验两个核心：① 总体是否“声画一致”偏好；② 想象力/训练是否放大或减弱这种偏好；③ 个体的“确定性”是否随训练而变化。
